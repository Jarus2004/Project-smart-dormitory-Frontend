เอกสารอธิบายการเพิ่ม Visitor Consent Modal
===========================================

วันที่จัดทำ: 2026-09-19

วัตถุประสงค์
------------
เพิ่ม modal ขอความยินยอมข้อมูลส่วนบุคคลตาม PDPA ก่อนผู้มาเยือนจะเข้าสู่แบบฟอร์มลงทะเบียนเข้าเยี่ยม

ไฟล์ที่แก้ไข
------------
1. src/componants/homepage/selection/HeroSection.tsx
   - เพิ่ม state สำหรับเปิด/ปิด modal
   - เพิ่ม state สำหรับ checkbox ยินยอม
   - เปลี่ยนการคลิก card ผู้มาเยือนจากการไปหน้า /visitor โดยตรงเป็นการเปิด modal
   - ปุ่ม "ยอมรับและไปต่อ" จะใช้งานได้เมื่อผู้ใช้ติ๊ก checkbox แล้วเท่านั้น
   - เมื่อยอมรับแล้วจึงนำทางไปที่ /visitor
   - เพิ่มปุ่มยกเลิก
   - คลิกพื้นที่ด้านนอก modal เพื่อปิด modal
   - กดปุ่ม Escape เพื่อปิด modal

2. src/componants/homepage/selection/HeroSection.module.css
   - เพิ่มรูปแบบพื้นหลังของ modal
   - เพิ่มรูปแบบกล่องข้อความ consent
   - เพิ่มรูปแบบ checkbox และปุ่มควบคุม
   - เพิ่ม responsive layout สำหรับหน้าจอมือถือ

ข้อความที่แสดงใน modal
----------------------
ข้าพเจ้ายินยอมให้เว็บไซต์เก็บรวบรวม ใช้ และเปิดเผยข้อมูลส่วนบุคคลของข้าพเจ้า รวมถึงข้อมูลที่ปรากฏในบัตรประจำตัวประชาชนและเอกสารที่ข้าพเจ้าอัปโหลด เพื่อวัตถุประสงค์ในการยืนยันตัวตน การให้บริการ และการดำเนินการที่เกี่ยวข้องตามที่เว็บไซต์กำหนด

ข้าพเจ้าได้รับทราบนโยบายความเป็นส่วนตัวของเว็บไซต์แล้ว และยินยอมให้ดำเนินการกับข้อมูลส่วนบุคคลดังกล่าวตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA)

Checkbox:
ข้าพเจ้าได้อ่านและยอมรับเงื่อนไขการเก็บรวบรวม ใช้ และเปิดเผยข้อมูลส่วนบุคคลข้างต้น

ลำดับการทำงาน
--------------
1. ผู้ใช้คลิก card "สำหรับผู้มาเยือน"
2. ระบบเปิด modal ขอความยินยอม
3. ระบบปิดใช้งานปุ่ม "ยอมรับและไปต่อ" จนกว่าจะติ๊ก checkbox
4. ผู้ใช้ติ๊ก checkbox เพื่อยืนยันการยอมรับ
5. ผู้ใช้กด "ยอมรับและไปต่อ"
6. ระบบนำทางไปหน้าแบบฟอร์มลงทะเบียนที่ /visitor

กรณีปิด modal
--------------
- กดปุ่ม "ยกเลิก": ปิด modal และล้างสถานะ checkbox
- คลิกพื้นหลัง modal: ปิด modal และล้างสถานะ checkbox
- กด Escape: ปิด modal และล้างสถานะ checkbox

การตรวจสอบ
----------
- npm run build: ผ่าน
- npx eslint src/componants/homepage/selection/HeroSection.tsx: ผ่าน
- npm run lint ทั้งโปรเจกต์: ยังมี error เดิมในไฟล์อื่นที่ไม่เกี่ยวข้องกับ modal นี้

หมายเหตุ
--------
การแสดง modal นี้ควบคุมเฉพาะการเข้าหน้า /visitor จาก card ผู้มาเยือนบนหน้าแรกเท่านั้น หากมีจุดอื่นที่นำทางไป /visitor โดยตรง จะไม่ได้ผ่าน modal นี้
