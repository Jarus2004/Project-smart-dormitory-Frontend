# Frontend AI Context

This folder contains focused AI-facing context for the frontend repository.
It supplements `AGENTS.md`; it does not replace or override the root rules.

## Contents

- `AI-CHANGELOG/`: AI-assisted change notes
- `spec-backend.md`: backend API contract alignment
- `spec-frontend.md`: frontend component and UX conventions
- `spec-consistency.md`: domain names, statuses, and error alignment
- `anti-bloat.md`: complexity control before adding code
- `pre-dormitory-checklist.md`: final verification checklist
- `runtime-rules.md`: legacy routing note; do not add new rules here

## Alignment Rules

- Keep frontend implementation aligned with the backend API contracts.
- Follow the current in-scope / out-of-scope boundaries.
- Do not introduce face-detection features in this term unless the project scope
  is explicitly changed.
